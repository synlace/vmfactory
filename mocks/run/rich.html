1c · lifecycle · scout flow — clone → scan (the files the sieve reads + the release inventory) → the scout emits routes as it reads, each clamping into a lane (no per-lane llm) with prebuilt booting while the scout still reads; skips are scan findings; losers park. The board stays open through promotion: the winning lane re-boots the canonical instance (promoting → final pass with the canonical target), and the board's last line IS the verdict.
